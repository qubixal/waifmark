Install & Boot

cd benchmark
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt        # installs waifmark + FastAPI app
cp .env.example .env  # add OPENROUTER_API_KEY / HF_TOKEN if you have them
waifmark              # ← boots at http://127.0.0.1:8001

#note: python 3.11+ recommended for vLLM, 3.10+ for llama.cpp

Before benchmarking

  • Set model in config.yaml under judges.model (e.g. google/gemma-4-31b-it:free) and model_under_test.name
  • Small models are sensitive to chat templates, so check vLLM --chat-template and config.yaml chat_template if scores look abnormally low.
  • Waifmark 2's test bank is proprietary; drop your own data/test_bank.json if you want to.

Scoring (v2 — breaking vs v1)

Agentic (deterministic)

score_100 = 100 × ( tool_syntax_accuracy × 0.3
                  + goal_completion        × 0.5
                  + error_recovery         × 0.2 )
  • tool_syntax_accuracy — fraction of steps with valid JSON.
  • goal_completion — 70% final-answer hit + 30% required-tool use (weight agentic.final_completion_weight).
  • error_recovery — next step succeeds and retries same action.

Roleplay (LLM-as-judge v2)

  • Rubric character_consistency 0.35 / instruction_following 0.25 / trap_resistance 0.25 / conversational_quality 0.15 in config.yaml.
  • Calibrated prompt with Aura v2 persona, hard caps for [DELETE]/boilerplate, confidence-weighted aggregation, heuristic fallback.
  • Triage flags: disagreement, boilerplate, low confidence <0.55, delete flag, heuristic, judge error, seeded spotcheck.

Project layout

benchmark/
  core/          engine: sandbox, client, scoring, serving
  evaluation/    judge v2 + triage v2
  api/           FastAPI backend (new app default)
  web/           frontend (Chart.js, vanilla JS)
  data/          test banks (proprietary not committed)
  tests/         pytest suite
  config.yaml    run configuration
  run.py         one-command boot helper

Security

  • Sandbox is a harness, not a boundary — disable allow_python3_tool: false for untrusted banks.
  • Backends spawned argv-based + start_new_session=True so killpg cleans workers. FastAPI binds 127.0.0.1 + CORS.
  • Never commit .env or data/test_bank.json.
